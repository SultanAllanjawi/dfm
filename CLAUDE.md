# `# Visual Style`

```
- Never create generic dashboards.
```

* `Every interface should feel premium and modern.`
* `Prioritize whitespace and visual hierarchy.`
* `Keep layouts clean and uncluttered.`
* `Use layered dark surfaces with subtle depth.`
* `Use tasteful gradients that enhance rather than distract.`
* `Glass effects should be subtle and only used when they improve the design.`
* `Use elegant shadows and soft borders.`
* `Every component should feel balanced and aligned.`

```
---
```

# `# Typography`

```
- Use Inter or Geist.
```

```
- Typography should create a clear visual hierarchy.
```

```
- Large, bold metrics should immediately draw attention.
```

```
- Secondary information should be quieter but still readable.
```

* `Avoid excessive font weights and unnecessary text.`


\# Final Quality Standard



Before considering any task complete, review the result against these standards.



The interface should feel:



\- Premium

\- Modern

\- Elegant

\- Fast

\- Clean

\- Purposeful

\- Production-ready



Avoid:



\- Generic admin dashboard layouts

\- Default Tailwind styling

\- Excessive borders

\- Inconsistent spacing

\- Flat or lifeless components

\- Abrupt state changes

\- Poor typography hierarchy

\- Cluttered interfaces



Every new feature should include:



\- Beautiful loading states

\- Empty states

\- Hover interactions

\- Smooth animations

\- Responsive behavior

\- Consistent spacing

\- Premium visual polish



If a screen does not feel like it belongs in a world-class SaaS product, continue refining it before presenting it.

## Avoid



\- Bootstrap styling

\- Generic admin templates

\- Flat, lifeless cards

\- Excessive borders

\- Bright neon colors

\- Overly saturated gradients

\- Inconsistent spacing

\- Abrupt animations

\- Dense, cluttered layouts

Before completing any UI task, review your work as if you were a senior product designer.



Do not stop at "functional."



Continue refining until the interface feels polished, cohesive, and worthy of a premium SaaS product.
